# Laboratorio

Código, datasets pequeños, esquemas y entornos reproducibles de la materia. La tecnología se define en `materia.yaml`; este template no presupone motor de base de datos, lenguaje ni runtime.

No versionar credenciales, datos privados, artefactos pesados ni dependencias regenerables.

## Archivos

- `calculadora_andy.xlsx`: calculadora de tasas y de préstamos (francés, alemán, directo y bullet, hasta 120 períodos). Copia corregida de una calculadora compartida (no oficial): agrega capitalización cuatrimestral y diaria, deja vacías las columnas que pasan de n y corrige el VF de la anualidad adelantada.
